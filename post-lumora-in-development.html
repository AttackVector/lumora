Lumora in development

17 Oct 2026Community

Lumora is a community project and it is still in development. The goal is a stable, easy to use Linux distribution with a familiar desktop: a top bar, a dock, and window buttons where you expect them.

An idea we would like help with

When someone installs Lumora for the first time, they land on a fresh desktop with no hints about what to do next. We would like a small welcome app that opens after install and walks them through the first steps.

  • A short tour of the top bar and the dock
  • One-click links to install common apps from Bazaar
  • A page for updates and drivers
  • Links to the documentation, the forum and the chat room

These are only ideas, and the app is not started yet. What it does is up to the people who build it.

How to help

We need designers for the screens, developers to build it, and writers for the text. You do not have to be an expert. Say hello in the discord server and tell us what you would like to work on.
