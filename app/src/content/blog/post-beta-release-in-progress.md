We are putting together the first beta build of Lumora 27. When it is ready, we will post it on the website
  and announce it here.

## What testers will be asked to try
* Boot the live session. Does it reach the desktop without errors?
* Run the installer on a blank disk. Does it open?
* Check that Wi-Fi, sound, the touchpad and screen brightness work.
* Use the dock and the top bar. Open and close a few apps.
* Restart after install and make sure the boot splash and login screen look right.

## How to report a problem
Write down your computer's make and model, what you did, what you expected, and what happened instead. A
photo of an error message helps a lot. Post it in the discord server, and I will pick it up.

<div class="callout">
  <p>Pre-release software can lose data. Test on a machine (or VM) that has nothing important on it.</p>
</div>
