We just uploaded our November 22 Build. Try it out!

## New Additions
* Native Dock has been replaced with Dash to Dock, Intellihide and other features now work! (Native dock will still be packaged, but D2D will be enabled by default)
* Updates have been defaulted to SECURITY only.
* Updated Gaze (Face recognition software)
* Fixed the Wi-Fi issue post install
* Our brand font (Bitter) is the default interface font systemwide!


## Known Issues
* Calamares shell shows when being autolaunched.
* Two programs crash on live boot.


## What our team is working on
* Fixing the bugs
* Fixing general GNOME stability
* Post install app
* Getting new default wallpapers (contacting photographers)

## What testers will be asked to try
* Boot the live session. Does it reach the desktop without errors?
* Run the installer on a blank disk. Does it open?
* Check that Wi-Fi, sound, the touchpad and screen brightness work.
* Use the dock and the top bar. Open and close a few apps.
* Restart after install and make sure the boot splash and login screen look right.

## How to report a problem
Write down your computer's make and model, what you did, what you expected, and what happened instead. A
photo of an error message helps a lot. Post it in the discord server, and I will pick it up.

<div class="callout">
  <p>Pre-release software can lose data. Test on a machine (or VM) that has nothing important on it.</p>
