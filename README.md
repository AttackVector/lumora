# Lumora

Lumora is a stable, easy to use Linux distribution built on Ubuntu. It is made for people who find it hard to switch to Linux, and it gives them a familiar desktop layout with a top bar and a dock at the bottom.

The word *lumora* means a gentle glow or radiance.

> **Status: beta.** Lumora 27 is in beta. The current build was compiled on 24 October 2026. It should work on most computers, but compatibility and stability are not guaranteed. Use it at your own risk, and back up anything you care about before installing. The final release is planned for late November or early December 2026.

## Features

- **Familiar desktop.** A top bar, a dock, and window buttons where you expect them. The layout is similar to a Mac-style desktop.
- **Snappy.** Designed to feel fast while you work. Your results may vary depending on your hardware.
- **Stable base.** Built on Ubuntu, so it receives Ubuntu's security and software updates. Lumora 27 will be supported until 2031.
- **Software included.** Firefox, Thunderbird and LibreOffice, plus Bazaar, a software center with thousands of extra apps.
- **Independent and private.** No tracking, no ads, and no account needed to download.

## System requirements

| | Minimum | Recommended |
|---|---|---|
| Processor | Dual core, 64-bit | Quad core, 3 GHz or faster |
| Memory | 4 GB RAM | 8 GB RAM or more |
| Disk space | 20 GB | 128 GB |

You also need a USB stick of at least 8 GB to install from.

After downloading, check the file before you use it. Run this and compare the result with the checksum on the release page:

```bash
sha256sum lumora-*-amd64.iso
```

## Try it and install it

1. Write the ISO to your USB stick with a tool such as balenaEtcher, Rufus or `dd`.
2. Restart your computer and boot from the USB stick. This usually means pressing F12, F10 or Esc during startup.
3. Try Lumora in the live session first. Nothing is changed on your computer until you choose to install.
4. When you are ready, run the installer from the live session.

If you are not sure, try the beta in a virtual machine or on a spare computer first.

## Getting help and reporting problems

The quickest way to get help is the Lumora Discord server: <https://discord.gg/73hWZujgpW>

When you report a problem, please include:

- your computer's make and model
- what you did
- what you expected to happen
- what happened instead
